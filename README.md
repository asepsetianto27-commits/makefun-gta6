Solmara Nights — a complete open-world crime game in the spirit of GTA 6: explore the sun-soaked coastal city of Solmara on foot and by car, steal cars, outrun the police, and run story missions. Playable in a desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
